# Banner SICAPDA (apresentação no SENAI)

- `banner-sicapda.png`: 3600 × 4800 px, proporção 3:4 (90 × 120 cm, ~100 dpi nesse tamanho).
- `banner-sicapda.pdf`: a mesma arte com textos em vetor, melhor para mandar à gráfica.
- `fonte/`: o HTML e os scripts que geram a arte. Para mudar um texto, edite `fonte/build.js` e rode `npm install && npm run build` dentro de `fonte/`.

O QR Code abre `https://fluxeteam.com.br/sicapda`.
