Perguntas frequentes

O aplicativo é seguro?

O arquivo é gerado pela equipe da Fluxe. O aplicativo só pede acesso à internet e guarda apenas o token de sessão, de forma criptografada.

Por que o Android avisa sobre “fonte desconhecida”?

Porque o aplicativo é instalado fora da Google Play. É um aviso padrão do Android para qualquer APK baixado de um site. Basta permitir a instalação para o navegador (ou gerenciador de arquivos) e, se quiser, desfazer a permissão depois.

Preciso criar uma conta nova?

Não. Use o mesmo e-mail e senha do painel web. Os dados e as permissões são os mesmos.

Funciona sem internet?

Não. O aplicativo consulta o servidor em tempo real para mostrar acessos e previsões, então precisa de conexão (Wi-Fi ou dados móveis).

E no iPhone?

Por enquanto o instalador é só para Android. No iPhone, acesse a versão web pelo navegador: ela também funciona bem no celular.

Como atualizo para uma versão nova?

Baixe o APK mais recente nesta página e instale por cima da versão atual. Se o Android recusar a atualização, desinstale a versão antiga e instale a nova: basta entrar de novo com a sua conta.
